# معلومات عيادة العقباوي لطب الأسنان (Al-Aqabawi Dental Clinic)
- **الموقع:** مدينة الشروق (Al-Shorouk City).
- **مواعيد العمل:** من ٤ مساءً إلى ١٠ مساءً يومياً ما عدا يوم الجمعة.
- **الطوارئ:** للحالات الطارئة جداً خارج مواعيد العمل يرجى الاتصال برقم الطوارئ المخصص للعيادة.
- **الأطباء:** د. محمد العقباوي، د. إبراهيم جمال.
